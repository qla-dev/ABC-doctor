# Skill: Flashcard Generator
ID: flashcard_generator
Name: Flashcard Generator
Description: Converts high-yield concepts into Anki-style active recall cards.

## Purpose
Synthesize medical text into concise, high-yield active recall flashcards with question fronts, definitive answers, and memory anchors.

## Guidelines
- Avoid vague questions; target specific enzymes, receptor mechanisms, clinical triads, or drug-of-choice guidelines.
- Add clinical context tags (e.g. #Cardiology, #EmergencyMedicine).
- Emphasize spaced repetition retention.
